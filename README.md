# УВМ — ассемблер и интерпретатор

Учебный проект по дисциплине «Конфигурационное управление» (РТУ МИРЭА,
сборник практических работ № 3, вариант 12). Реализованы текстовый
ассемблер, генератор машинного кода и интерпретатор виртуальной машины
с раздельной памятью команд и данных.

## Установка и проверка

Требуется Python 3.11 или новее. Внешних зависимостей времени выполнения нет.
Для запуска тестов установите pytest:

```sh
python -m pip install pytest
python -m pytest -q
./run.sh test
```

Запускайте команды из корня проекта.

## Командная строка

Общая форма вызова — `./run.sh {asm|run|test} [параметры]`.

### Ассемблирование

```sh
./run.sh asm --input examples/spec_test.asm --output /tmp/spec.bin
./run.sh asm --input examples/spec_test.asm --test
```

`asm` принимает текстовый исходный файл через `--input`, путь машинного
файла через `--output` и диагностический режим `--test`. В обычном режиме
создаётся двоичный файл, а в режиме `--test` печатаются IR и байты команд.

### Выполнение

```sh
./run.sh run --input /tmp/spec.bin --dump /tmp/memory.csv
./run.sh run --input /tmp/spec.bin --dump /tmp/memory.csv --range 0:64
```

`run` загружает машинный файл в память команд и выполняет его. `--dump`
задаёт необязательный CSV-дамп памяти данных; `--range start:end`
ограничивает адреса дампа полуинтервалом `[start, end)`. Без `--range`
дампятся ячейки, имеющие ненулевые значения.

## Язык ассемблера

Исходник — обычный текстовый файл: одна инструкция на строку. Мнемоника
записывается заглавными буквами; после неё следуют целочисленные операнды,
разделённые запятыми. Числа могут быть десятичными или шестнадцатеричными
с префиксом `0x`. Пустые строки и текст после `#` игнорируются. Метки,
регистры и директивы данных не используются. Адреса относятся к памяти
данных, а порядок операндов соответствует полям ISA.

```asm
# Записать константу 765 в ячейку 464
LOAD_CONST 464, 765
```

Полный перечень мнемоник, семантика, разметка битов и примеры приведены в
[docs/isa.md](docs/isa.md).

## Пример

```sh
./run.sh asm --input examples/spec_test.asm --output /tmp/spec.bin
./run.sh run --input /tmp/spec.bin --dump /tmp/spec.csv --range 460:490
```

CSV содержит столбцы `addr`, `value_hex` и `value_dec`. Память команд и
память данных независимы: выполнение кода не перезаписывает инструкции.
Диапазон `start:end` полуоткрытый. При вызове `run` без `--range` CSV
содержит только ненулевые ячейки; `--range` допускает включение нулевых.

## Результат тестовой задачи

Программы `examples/vector_add_1.asm`, `vector_add_2.asm` и
`vector_add_3.asm` прибавляют 128 к каждому из десяти входных элементов.
Результат записывается по адресам `400..409`. Сложение ограничено 32 битами:
переполнение оборачивается по модулю `2^32`.

```sh
./run.sh asm --input examples/vector_add_1.asm --output /tmp/vector.bin
./run.sh run --input /tmp/vector.bin --dump /tmp/vector.csv --range 400:410
```

Автотесты проверяют CSV-адреса, десятичные значения и их восьмизначное
шестнадцатеричное представление для всех трёх наборов данных.

## Структура

- `src/assembler.py` — разбор текстового языка в IR.
- `src/codegen.py` — кодирование и декодирование little-endian инструкций.
- `src/memory.py` — раздельная память команд/данных и CSV-дамп.
- `src/interpreter.py` — цикл исполнения и арифметико-логическое устройство.
- `src/cli.py` — интерфейс командной строки.
- `tests/` — проверки ISA, ассемблера и примеров.
- `examples/` — тестовые программы на языке ассемблера.
